## Demonstration workflow

1. Select workspace mode `Demonstration`.
2. Select organization `Demo Organization`.
3. Confirm the blue `Demonstration Mode` banner.
4. Run the guided flow:
   - Knowledge Manager
   - Governance
   - Organizational Memory
   - Organizational Intelligence
   - Grounded answer view
   - Audit

## Demonstration guarantees

- Synthetic data only
- No customer information
- No operational authority
- No cross-over with production runtime data

## Reset demonstration

Use `Reset Demo` from:

- Demonstration walkthrough page
- Workspace page

Reset restores synthetic demonstration records and state to the canonical
baseline.
